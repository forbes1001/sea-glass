# Sea Glass & Shards

Create a handmade crafts store for a local artisan who makes crafts using broken ceramics and sea glass collected from the beach. Include product categories, search, featured items, product details, shopping basket, contact page, capture email addresses and mobile-friendly design. Use warm handmade styling with light pastel colours and tones.
